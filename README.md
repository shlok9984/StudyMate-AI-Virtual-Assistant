# StudyMate AI - Virtual AI Assistant

## Project Overview
StudyMate AI is an AI-powered virtual assistant that helps college students improve learning and productivity.

## Features
1. AI Chat Assistant
2. PDF Notes Summarizer
3. AI Quiz Generator
4. Programming Code Explainer
5. Personal Study Planner

## Technologies Used
- Python
- Streamlit
- Groq API
- SQLite
- PyPDF

## Installation
1. Clone the repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Configure your Groq API key.
4. Run using `streamlit run app.py`.
